Attendance Management System
_________________________________

[Overview]

"The Attendance Management 
System is a web-based application that
helps schools and colleges manage 
student attendance efficiently.
It allows users to add students, 
mark attendance, and generate attendance 
reports."

[Features]
- User Login
- Dashboard
- Student Management
- Mark Attendance
- Attendance Reports
- Responsive Design
_____________________________________
